# IELTS Ultimate — Complete IELTS Learning Platform

A modern, responsive IELTS preparation SaaS application built with **Next.js (App Router)**, **React**, **Custom CSS**, **GSAP**, **Recharts**, and **Lucide Icons**.

## Features

- **Dashboard (`/dashboard`)**: Overall & module band scores, target & exam countdown modals, 14-day interactive study streak calendar, weekly study roadmap, Recharts performance analytics, and skill breakdown.
- **Full Mock Test (`/mock-test`)**: 2h 40m 4-module simulated examination workflow with per-section timers and LocalStorage autosave.
- **Reading (`/reading`)**: Split-screen examination workspace with adjustable panel split, text highlighting, personal notes, and 14 IELTS Reading question types.
- **Listening (`/listening`)**: 4-part practice sets with speed-adjustable Web Speech & transcript audio player, orientation map reference, and 8 question types.
- **Writing (`/writing`)**: Academic Task 1 charts/tables/diagrams/maps & Task 2 essays, live word counter, custom prompt creator, and local demo rubric feedback.
- **Speaking (`/speaking` & `/cue-card-coach`)**: Parts 1–3 interview simulator with browser `MediaRecorder` support (plus demo timer fallback) and 60s cue card prep trainer.
- **Learning & Social**: Question Types Masterclass (`/question-types`), Study Plan Builder (`/study-plan`), Vocabulary Flashcards & Quizzes (`/vocabulary`), 10 Study Utilities (`/tools`), Band Battle Arena (`/band-battle`), Community & Study Groups (`/community`), Teachers & Partners (`/people`), Referrals (`/invite-friends`), Account Pages, and Admin Demo Console (`/admin`).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
